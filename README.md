# HoneyClient Website

This is the fully responsive, glassmorphic landing page for HoneyClient.

## What's inside
- `index.html`: The structure of the site.
- `style.css`: All the styling, glassmorphism, and honey drip animations.
- `script.js`: The parallax mouse effect and fade-in animations.
- `assets/`: This folder already contains `app-icon.svg` and `honeycomb.svg`, which are exact pixel-art vector recreations of your images so the site works immediately out of the box.

## How to deploy to GitHub Pages
1. Create a new repository in the HoneyClient org named exactly `HoneyClient.github.io`.
2. Upload all the files inside this folder (including the `assets` folder) to the root of the repository.
3. Go to Settings > Pages, set the Branch to `main` and `/ (root)`, and hit Save.
4. Your site will be live at `https://honeyclient.github.io/`.
